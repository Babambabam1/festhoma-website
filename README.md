# 🎉 FestHoma 2026 - Official Website

**The Annual Cultural Fest of St. Thomas' School, Kidderpore**
*November 17-19, 2026*

A complete modern redesign of the FestHoma website with cutting-edge web techniques.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🌐 Hosting on GitHub Pages

This project is configured to deploy automatically to GitHub Pages.

1. Create a GitHub repository named `festhoma-2026`
2. Push your code to the repository
3. Enable GitHub Pages in the repository settings (Settings → Pages → Source: main → /dist)
4. Your site will be live at: `https://[your-username].github.io/festhoma-2026/`

## 🛠️ Tech Stack

- **React 18** with Vite
- **Framer Motion** for animations
- **react-intersection-observer** for scroll detection
- **Lenis** for smooth scrolling
- **Three.js / Three Fiber** ready for 3D graphics
- **Modern CSS** with custom properties and design tokens

## 📱 Features

- Smooth scrolling with Lenis
- Animated particle background
- Live countdown timer
- Interactive event filtering
- 3-day schedule timeline
- Gallery with lightbox
- Fully responsive design
- Glassmorphism effects
- Loading screen animation
